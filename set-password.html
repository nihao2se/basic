🔐 Change the admin password

Type your new password. This page never sends anything anywhere – it only prints two values for you to paste into index.html.

  1. Open index.html in Notepad (or any text editor).
  2. Press Ctrl + F and search for const SALT=.
  3. Replace that whole line (from const SALT= to N=50000) with the line above, then save.
  4. Upload the new index.html to GitHub (or replace it on your PC).
⚠ This password check runs inside the browser. It keeps casual visitors out, but it is not real server security. See the README.
